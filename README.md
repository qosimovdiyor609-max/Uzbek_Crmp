# 🇺🇿 O'zbek RP — CRMP

O'zbekiston ruhidagi original 3D RP o'yin prototipi.

## Hozirgi prototip

- 3D shahar va yo'llar
- O'zbekcha HUD va menyu
- O'yinchi yurishi: WASD
- Yugurish: Shift
- Mashinaga kirish/chiqish: E
- Pul ko'rsatkichi
- Markaziy maydon va O'zbekiston ranglaridagi shahar belgisi

## Texnologiya

- Three.js
- TypeScript
- Vite

## Ishga tushirish

```bash
npm install
npm run dev
```
